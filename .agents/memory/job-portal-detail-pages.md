# 채용 사이트 공고 본문 수집

## 규칙
겉 공고 페이지의 HTML 텍스트는 내비게이션·안내 보일러플레이트뿐이고, 실제 본문은 별도 상세 페이지(iframe/ajax)에 있다. 사람인은 rec_idx 기반 view-detail 페이지, 잡코리아는 Gno 기반 iframe 페이지가 본문이다.

**Why:** 겉 페이지 텍스트가 수천 자라 "텍스트 충분" 길이 휴리스틱을 통과해버려, 상세 페이지 폴백도 이미지 OCR 폴백도 트리거되지 않는다.

**How to apply:** 알려진 사이트의 상세 페이지 본문은 짧더라도(이미지 공고) 겉 페이지보다 무조건 우선 채택해야 OCR 폴백이 본문 이미지로 동작한다. 이미지 공고는 잡코리아에 흔하다. 삭제된 공고는 200 + JS alert 페이지를 주므로 빈 본문을 성공으로 돌려주면 안 된다. 잡코리아 검색 페이지는 봇을 400으로 막지만 목록·상세는 브라우저 UA+Referer로 접근 가능.
