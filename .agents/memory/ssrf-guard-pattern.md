# 사용자 URL fetch의 SSRF 방어

## 규칙
- 사설 IP 판별은 문자열 prefix 검사 금지 — 바이트 단위로 파싱해 대역을 검사할 것. URL 정규화가 IPv4-매핑 IPv6를 16진 표기로 바꾸므로 prefix 매칭은 우회된다.
- DNS 리바인딩 방지: 검증 시점 조회와 실제 연결 주소가 달라질 수 있으므로, 연결 시점(커스텀 lookup)에서 사설 주소를 거부해야 한다. 결과 중 하나라도 사설이면 전부 거부.
- 리다이렉트는 수동 처리로 매 홉 재검증.

**Why:** 완료 코드 리뷰가 이 두 우회(16진 매핑, 리바인딩)를 근거로 작업을 반려한다.

**How to apply:** 새 URL-fetch 기능에는 api-server의 기존 SSRF-safe fetch 공용 모듈을 재사용하고 자체 가드를 새로 만들지 말 것.
