---
name: 다중 서버 운영 집계 시각
description: 여러 API 인스턴스가 공유하는 운영 이벤트 집계에서 시계 편차를 막는 기준
---

여러 인스턴스가 공유하는 운영 이벤트를 집계할 때 기록 시각, 시간 구간의 양 끝, 쿨다운 선점 시각, 외부에 표시하는 구간 종료 시각은 한 원자 작업 안에서 얻은 PostgreSQL 공통 시각을 함께 사용한다.

**Why:** 각 서버의 시스템 시각을 섞으면 인스턴스 간 시계 편차가 구간 및 쿨다운 경계에서 서로 다른 집계와 알림 결과를 만들 수 있다.

**How to apply:** 데이터베이스에 저장된 운영 이벤트와 공유 알림 상태를 함께 판정하는 다중 인스턴스 모니터에 적용한다. 호출자가 전달한 시각은 데이터베이스 기반 운영 판정에 사용하지 않는다.
