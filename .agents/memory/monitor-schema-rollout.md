---
name: 운영 모니터 스키마 배포
description: 운영 모니터가 새 PostgreSQL 테이블을 사용할 때의 배포 및 CI 원칙
---

운영 모니터용 테이블도 기능 코드와 함께 재실행 가능한 마이그레이션을 제공하고, API 시작 전에 적용해야 한다. CI의 빈 PostgreSQL에도 같은 마이그레이션을 적용한 뒤 실제 저장 경로를 검사한다.

**Why:** 스키마 선언과 격리 테스트만 있으면 기존 운영 DB에는 테이블이 생기지 않으며, 모니터 오류가 로그로만 처리되어 배포 후 감지가 조용히 멈출 수 있다.

**How to apply:** 운영 모니터에 영속 저장소를 추가하거나 변경할 때 API 시작 경로와 CI 테스트 경로가 동일한 마이그레이션을 선행하는지 함께 확인한다.
