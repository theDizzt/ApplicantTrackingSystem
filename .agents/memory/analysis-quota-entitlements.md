---
name: 심사 한도·특권 안전성
description: 월간 심사 한도와 서버 관리 무제한 권한을 안전하게 유지하는 설계 원칙
---

운영자급 무제한 권한은 사용자가 변경하거나 해지할 수 있는 일반 구독 상태와 분리된 서버 관리 권한으로 유지한다. 월별 사용량 초기화와 1회 차감은 같은 사용자 행을 잠근 단일 트랜잭션 안에서 처리한다.

**Why:** 구독 플랜에 특권을 섞으면 일반 구독 변경으로 특권이 사라질 수 있다. 월 경계에서 초기화와 차감을 분리하면 동시 요청이 서로의 증가분을 덮어써 실제 사용 횟수보다 적게 기록될 수 있다.

**How to apply:** 새로운 예외 계정이나 월간 한도 기능을 추가할 때 일반 구독 API가 서버 관리 권한을 수정하지 않는지 확인하고, 월 경계 동시 요청 회귀 테스트를 함께 유지한다.
