# AI 서류 심사관
### 지원자의 합격률을 높이는 AI 채용 서류 분석 플랫폼

---

## 제품 개요

**AI 서류 심사관**은 취업 준비생과 이직자가 채용 서류를 제출하기 전에 AI를 통해 완성도를 객관적으로 점검할 수 있는 서비스입니다.

이력서와 채용 공고를 함께 분석해 직무 적합도·언어 품질·AI 생성 여부 등 4개 영역의 정량 점수와 구체적인 개선 피드백을 제공합니다. 서류 심사를 통과한 뒤에는 분석 결과를 기반으로 맞춤형 AI 면접 연습까지 이어집니다.

---

## 핵심 기능

### 1. AI 서류 심사 — 4개 영역 정량 평가

이력서와 채용 공고를 입력하면 AI가 아래 4가지 영역을 분석하고 종합 점수를 산출합니다.

| 영역 | 분석 내용 |
|------|-----------|
| **직무 적합도** | 이력서의 경험·기술이 채용 공고 요건과 얼마나 일치하는지 |
| **언어 품질** | 문장의 명확성, 논리 구조, 전문 용어 적절성 |
| **AI 생성 감지** | 채용 담당자가 기피하는 AI 작성 패턴 탐지 |
| **전반적 완성도** | 구성, 분량, 핵심 정보 포함 여부 |

각 영역별 세부 피드백과 우선순위 개선 제안이 함께 제공되어 어디서부터 고쳐야 할지 명확하게 알 수 있습니다.

추가로, 공고 직무 내용과 자기소개서의 **문장 유사도(임베딩 기반)** 를 점수화하고, 보조 심사 모델을 활용한 **다중 AI 심사 의견**을 함께 제시해 더 폭넓은 관점을 제공합니다.

---

### 2. 이력서 관리

- 리치 텍스트 에디터(TipTap)로 이력서를 직접 작성하거나 편집
- **PDF / Word 파일 업로드** 시 텍스트를 자동 추출해 에디터에 불러오기
  - **스캔(이미지) PDF OCR**: 텍스트가 없는 스캔 이력서도 비전 AI로 자동 인식
  - macOS에서 흔한 한글 자소 분리 파일명·본문을 자동 정규화
- **AI 맞춤법 검사**: 한국어 문맥에 맞는 표현 교정 및 오류 탐지
- **AI 커리어 분석**: 강점·NCS 직무분류·추천 직무·연봉 가이드·오탈자/날짜 점검·요약을 자동 제공
- **이력서 PDF 다운로드**: 3종 템플릿 중 선택해 인쇄용 PDF로 출력
- 여러 버전의 이력서를 저장해 직무별로 관리

---

### 3. 채용 공고 자동 수집 및 분석

- 회사명 또는 직무 키워드로 **사람인 채용 공고 자동 수집**
- **채용 공고 URL 가져오기**: 공고 링크 1건을 붙여넣으면 내용을 자동 정리(이미지 공고는 OCR, 안전한 URL 접근 가드 적용)
- AI가 공고를 정규화해 경력 조건·학력·모집 분야를 정리
- **기업 맞춤 추천**: 이력서 내용과 유사한 포지션을 AI가 추천
- 지원 회사별 공고 정보를 저장해 심사 시 자동 참조

---

### 4. GitHub URL 연동 기술 역량 평가

- 이력서에 GitHub 저장소 URL을 포함하면 AI가 자동으로 분석
- 저장소별 사용 언어 비중, 커밋 활동량, 프로젝트 구성 품질 평가
- 채용 공고의 기술 요건과 실제 GitHub 기여 이력을 비교해 적합도에 반영

---

### 5. AI 맞춤 면접 연습

서류 심사 결과를 기반으로 **약점 영역 중심의 압박 면접 질문**을 자동 생성합니다.

- 직무 적합도·언어 품질 등 낮은 점수 영역에서 예상 질문 도출
- 사용자 답변에 대한 실시간 AI 피드백 (논리성·구체성·전달력)
- 면접 세션 이력 저장으로 반복 연습 및 성장 추이 확인

---

### 6. 대시보드

- 이력서 수, 분석 횟수, 심사 평균 점수 등 활동 현황 요약
- 구독 플랜별 월간 잔여 사용 횟수 실시간 확인
- 최근 분석 결과와 면접 세션 빠른 접근

## AI 분석 기술

| 항목 | 내용 |
|------|------|
| **AI 모델** | 최신 GPT 계열 주 모델 + 보조 심사 모델 최대 2종 (OpenAI 호환 API) |
| **한국어 최적화** | 한국어 채용 시장 특성에 맞춘 프롬프트 설계 |
| **구조화 출력** | JSON Schema 기반 정형 응답으로 일관된 점수·피드백 보장 |
| **문장 유사도** | 임베딩 기반 직무↔자소서 적합도 정량화 |
| **비전 OCR** | 스캔(이미지) PDF 이력서·공고를 이미지 인식으로 텍스트화 |
| **외부 데이터 연동** | GitHub API, 사람인·잡코리아 채용 공고 실시간 수집 |

## 기대 효과

**지원자 관점**
- 서류 통과율 향상: 제출 전 객관적인 완성도 점검으로 치명적 약점 제거

- AI 생성 서류 판별 지원: 지원자의 AI 의존도 사전 파악 가능
- 직무 적합도 점수를 참고 자료로 활용 가능
