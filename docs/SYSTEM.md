# My ATS — 시스템 설명서

> **My ATS**는 한국 구직자를 위한 AI 기반 서류 심사 SaaS입니다.  
> 이력서를 등록하고 지원 공고와 매칭하면 AI가 서류를 심사하고 면접을 도와줍니다.

## 2. 핵심 기능

### 📄 이력서 관리
- 리치 텍스트 에디터(TipTap)로 이력서·자기소개서 작성
- PDF·Word 파일 업로드 및 텍스트 추출
- 희망 연봉, 사진 URL 등 부가 정보 관리
- **맞춤법·표현 검토**: AI가 한국어 문장의 어색한 표현과 오류를 교정

### 🏢 지원 회사 관리
- 회사명, 사이트 URL, 채용공고 URL, 인재상, 직무설명 등 직접 입력
- **분류 필드**: 경력구분(신입·1년이내·3년이내), 학력(전문대·대학교·석사), 모집분야(개발·기획·디자인·영업·품질관리·테스터·기타)
- **채용공고 자동 수집**: 필터 조건으로 사람인 실시간 스크래핑 + AI 보강
- **AI 기업 추천**: 이력서 내용 기반으로 적합 기업을 AI가 추천
- 매주 월요일 09:00 KST 자동 동기화(스케줄러)

### 🔍 AI 서류 심사 (핵심)
- 이력서 + 지원 회사를 선택하면 AI가 다차원 심사 수행
- GitHub/포트폴리오 URL을 자동 탐지·분석해 기술 역량 평가에 반영
- 최저임금(2026년 기준 10,030원/시) 대비 희망 연봉 적정성 자동 판단
- 결과는 즉시 저장되며 언제든지 재열람 가능

### 🎤 AI 면접 연습
- 서류 심사 결과를 기반으로 맞춤 면접 질문 생성
- 사용자가 답변 → AI가 피드백 → 반복 연습
- 면접 세션별 대화 이력 보관

### 📊 대시보드
- 이력서·서류 심사·면접 연습 현황 요약
- 월간 분석 사용량 및 구독 상태 표시

## 3. 사용자 플로우

```
회원가입 / 로그인
    │
    ├─ 이력서 등록 (직접 작성 또는 파일 업로드)
    │       └─ 맞춤법 검토 (선택)
    │
    ├─ 지원 회사 등록
    │       ├─ 직접 입력
    │       └─ 채용공고 자동 수집 (필터 → 사람인 스크래핑 → AI 보강)
    │
    ├─ AI 서류 심사 생성
    │       └─ 이력서 + 회사 선택 → AI 분석 → 점수 및 피드백 확인
    │
    └─ AI 면접 연습
            └─ 심사 결과 기반 질문 → 답변 → 피드백 반복
```

## 5. AI 분석 항목

서류 심사는 다음 4개 영역을 각각 0~100점으로 평가합니다.

| 항목 | 설명 |
|---|---|
| **AI 작성 감지 점수** | AI 도구로 작성된 문서 여부 탐지 |
| **언어 품질 점수** | 한국어 문장력·표현력·어휘 수준 평가 |
| **직무 적합도 점수** | 이력서 내용과 채용 공고 요건의 일치도 |
| **종합 점수** | 세 항목 가중 평균 |

추가 분석:
- **URL 분석**: GitHub 저장소 언어·스타·활동량, 포트폴리오 접근 가능 여부
- **기술 스킬·성격·조직 적합도**: 이력서 전체 맥락 기반 종합 평가
- **개선 제안**: 합격률을 높이기 위한 구체적 수정 가이드

## 6. 채용공고 수집 방식

```
사용자가 필터 선택 (경력 / 학력 / 모집분야)
    │
    ├─ 1단계: 사람인 공개 검색 페이지 스크래핑 (cheerio, 최대 8건)
    │         URL: saramin.co.kr/zf_user/search/recruit
    │
    ├─ 2단계: 잡코리아 검색 URL 생성 (CSR 앱이라 직접 파싱 불가)
    │         URL: jobkorea.co.kr/Search/?stext=…
    │
    └─ 3단계: AI 보강
              - 사람인 공고: URL 유지, 누락 정보 보완
              - 잡코리아 URL: AI가 조건에 맞는 공고 생성 + 잡코리아 링크 연결
              - 총 6건 이하 반환
```

> **참고**: 잡코리아는 React CSR 앱으로 서버 fetch 시 채용 데이터가 없어 직접 파싱 불가.  
> 사람인 API 키(`SARAMIN_API_KEY`)가 환경변수에 설정되면 공식 API 연동으로 업그레이드 가능.
