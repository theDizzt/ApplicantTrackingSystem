점검일: 2026-11-09 · 방법: 프롬프트·코드 정적 점검 (실행 검증 아님)

원칙: AI 판단은 **사용자가 넣은 자료(이력서·자기소개서·채용 공고)**와 **서버가 실제로 조회한 자료**만 근거로 해야 합니다. 모델이 원래 알고 있는 지식으로 사실을 만들어 내면, 모델을 바꿀 때마다 결과가 달라지고 출처를 댈 수 없습니다.

## 이미 막혀 있는 곳 (유지)

- 서류 심사 근거 인용문은 서버가 이력서 원문과 대조해 `quoteVerified` / `evidenceVerified`로 표시 (`lib/score-evidence.ts`)
- 면접 질문·평가·꼬리 질문은 "제공된 회사명·인재상·공고 기준, 다른 회사로 바꾸지 말 것"을 명시
- 불합격 원인 리포트는 "심사 결과에 없는 사실을 지어내지 말 것"을 명시
- 자기소개서 정리는 "원문에 없는 정보는 추측하지 않음"을 명시
- 논문은 이력서 정보만 사용하고, 외부 대조는 서버가 Crossref·OpenAlex·KCI에서 실제 조회
- HASA 웹 검색 에이전트(`/v1/agent/chat`)는 사용하지 않음
